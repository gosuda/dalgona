# Providers

The model package MUST expose one normalized stream for every provider. A provider MUST NOT expose vendor types to the agent. Request and stream JSON MUST use `encoding/json/jsontext` token and value APIs. Reflection-based JSON coding is permitted only for cold model-list responses.

## Requests

A request MUST contain a model id, messages, and optional tools. A model id MUST use `<provider>/<model>`. Tool schemas MUST disable strict-mode validation. Missing context windows MUST default to 128000 tokens. Adapters MUST NOT select behavior with model-name conditionals.

The OpenAI provider MUST use `POST /responses`. `OPENAI_BASE_URL` MAY override its base URL. OpenAI function tools MUST use `type:function` with `strict:false`. An OpenAI freeform tool MUST use `type:custom`. Function history MUST use `function_call` and `function_call_output` items. Custom history MUST use `custom_tool_call` with text input and `custom_tool_call_output` for its result. Reasoning effort MUST use `reasoning.effort`, with summary `auto` and `reasoning.encrypted_content` included.

Anthropic MUST use `POST /messages`. Its system prompt MUST be an array of text blocks. The system block and the final block of the newest user message MUST carry `cache_control:{"type":"ephemeral"}`. The last tool definition MUST carry the same marker. Adaptive reasoning MUST use `thinking.type:adaptive`, display `summarized`, and `output_config.effort`. Effort MUST map minimal and low to `low`, medium to `medium`, and higher levels to `high`.

Chat-compatible providers MUST use `POST /chat/completions`. A non-empty request system prompt MUST be the leading `system` message. Assistant tool calls MUST precede their `tool` result messages. User text in a message that also carries tool results MUST follow those `tool` messages. Streaming requests MUST set `stream_options.include_usage:true`. Reasoning MUST use `reasoning_effort`.

Google MUST use `POST /v1beta/models/<model>:streamGenerateContent?alt=sse`. Tools MUST share one `functionDeclarations` array. JSON schemas MUST use `parametersJsonSchema`. A scalar `const` keyword MUST become a one-value `enum`. An object or array `const` MUST stay unchanged. A property named `const` under `properties`, `patternProperties`, `$defs`, `definitions`, or `dependentSchemas` is a name, not a keyword, and MUST stay unchanged. Function responses MUST use the tool name and an `output` or `error` string. Reasoning MUST use `thinkingConfig.includeThoughts:true` and a `thinkingLevel` of `MINIMAL`, `LOW`, `MEDIUM`, or `HIGH`.

Outside OpenAI, a freeform tool MUST remain a function tool. Its schema MUST contain one string property named `input`. Its arguments MUST have the form `{"input":"..."}`. The stream decoder MUST return the input text and set `Freeform`. An empty string is valid input. A missing or non-string `input` MUST fail the stream. Tool result output that is a JSON string MUST be sent as its unquoted text on every provider.

API keys MUST come from the caller callback or the provider environment variable. A configured base URL MUST replace the default endpoint.

## Subscription and IDE providers

OAuth adapters MUST take their credential from a caller callback. `oauth.Source` MUST load the stored token once. It MUST refresh the token through `oauth.Refresh` when the token expires within 60 seconds. A token without an expiry MUST NOT refresh. Concurrent callers MUST share one refresh. A refresh MUST keep the previous account when the response carries none. The source MUST call `Save` after each successful refresh. A refresh failure MUST return an error and MUST keep the previous token for the next call. A save failure MUST return an error and MUST keep the refreshed token, because the refresh grant MAY have revoked the previous refresh token. The next call MUST retry the save without a new refresh.

The `chatgpt` provider MUST send the OpenAI Responses request to `https://chatgpt.com/backend-api/codex/responses`. Each request MUST carry `Authorization: Bearer <access>`, `chatgpt-account-id`, `OpenAI-Beta: responses=experimental`, and `originator: codex_cli_rs`. A token without an account id MUST fail before the request is sent. An empty system prompt MUST become `You are a helpful assistant.`. Stream decoding MUST follow the OpenAI rules. `Models` MUST return the static Codex list in donor priority order, with donor context windows and effort levels.

The `antigravity` provider MUST send `POST /v1internal:streamGenerateContent?alt=sse` to `https://daily-cloudcode-pa.googleapis.com`. The body MUST be the envelope `{project, requestId, request, model, userAgent:"antigravity"}`. `request` MUST be the Google request body. `requestId` MUST have the form `agent/<id>/<unix ms>/<id>/<step>`, where `<step>` is the message count and at least 1. The `User-Agent` header MUST be `antigravity/hub/<version> (aidev_client; os_type=<os>; arch=<arch>; cl=<changelist>)`. Each SSE event MUST carry the Google response under `response`. An event without `response` MUST decode as a Google response. Decoding MUST follow the Google rules.

Antigravity MUST resolve its project once per provider and reuse it. A configured project MUST skip discovery. Discovery MUST call `loadCodeAssist` with `metadata.ideType=ANTIGRAVITY`. When the response has no paid tier and names a project, discovery MUST call `loadCodeAssist` again with that project. A response that does not allow `free-tier` and gives an ineligibility reason for it MUST fail with that reason and its validation URL. A response without `currentTier` MUST start `onboardUser` with `tierId=free-tier`. Discovery MUST poll the returned operation once per second until it is done, for at most 30 seconds. A done operation with an error or without a response MUST fail. Discovery MUST then call `loadCodeAssist` again and MUST fail when no project is returned. `Models` MUST return the static donor list of Gemini models that use thinking levels. A model with an effort route MUST send the routed wire model for the requested effort, else its default wire model.

The `devin` provider MUST use Connect on `https://server.codeium.com`. The credential is `DEVIN_API_KEY` or the Devin OAuth token. `GetUserJwt` MUST first send the credential with the `devin-session-token$` prefix. After an HTTP 401 it MUST send the raw credential. The provider MUST cache the JWT until 60 seconds before its `exp` claim. A JWT without `exp` MUST stay cached until a chat request returns 401. After a 401 from a cached JWT, the provider MUST exchange a new JWT and repeat the request once.

Devin chat MUST send one gzip-compressed Connect frame to `GetChatMessage` with request type 5, planner mode 1, tool choice `auto`, an ephemeral system prompt cache, and parallel tool calls disabled. The metadata MUST identify `devin-cli` `3000.11.3` with IDE type `chisel` and MUST carry the JWT. User text MUST use source 1. Assistant turns MUST use source 2, with reasoning text placed before the visible text. Tool results MUST use source 4 and precede user text of the same message. Tool call ids MUST keep only `[A-Za-z0-9_-]`, MUST be cut to 40 characters, and MUST gain a `_dupN` suffix on collision. A call and its result MUST map to the same wire id.

Devin response frames MAY be gzip-compressed. A decompressed frame larger than 16 MiB MUST fail. Tool call deltas MUST join by id. A delta without an id MUST extend the most recent call. A delta that repeats the previous arguments as its prefix MUST replace them. Tool calls MUST be emitted only after a clean end of stream. Usage counters MUST keep their maximum over the stream. Stop reason 3 MUST map to `length`. Any tool call MUST map to `toolUse`. Reasons 0, 2, and 10 MUST map to `stop`. Other reasons MUST fail. An end-of-stream trailer with an error MUST fail with the HTTP status of its Connect code. A stream that ends without an end-of-stream frame and without a stop reason MUST fail. `Models` MUST call `GetCliModelConfigs` and MUST skip disabled, duplicate, and router models.

The `cursor` provider MUST open one HTTP/2 Connect stream to `POST https://api2.cursor.sh/agent.v1.AgentService/Run` per attempt. The request body MUST stay open for client frames while the response streams. The first frame MUST be the run request. The client MUST send a heartbeat frame every five seconds. Requests MUST carry `Authorization: Bearer <access>`, `x-ghost-mode: true`, `x-cursor-client-type: cli`, the donor client version, and a fresh `x-request-id`.

The run request MUST carry the conversation id, the model id as requested and displayed model, and the conversation state. The root prompt list MUST start with the system prompt blob `{"role":"system","content":...}`, where an empty system prompt becomes `You are a helpful assistant.`. Earlier messages MUST follow as JSON blobs in the donor format: user text, assistant text with `tool-call` parts, and `tool` messages with `tool-result` parts. A blob id MUST be the SHA-256 of its bytes. When the last message is user text, that text MUST be the user message action. Otherwise the action MUST be resume. A stored checkpoint whose first root prompt equals the current system blob MUST supply the other state fields. Its root prompts and turns MUST be replaced.

The provider MUST answer each blob read from the request blobs, then from blobs the server stored. A missing blob MUST be answered without data. A blob write MUST be stored before the reply. The provider MUST store each checkpoint. A request-context exec MUST be answered with the request tools as MCP definitions. Each definition MUST carry the tool schema as a `google.protobuf.Value` without `oneOf`, `anyOf`, or `allOf` members. The tool named `exec` MUST NOT be advertised, because the shell exec frame runs it.

Shell, shell-stream, and MCP exec frames MUST run through the `InBand` callback exactly once. A shell frame MUST map to the tool `exec` with `command` and, when present, `cwd` and `timeout_ms`. The `timeout_ms` value MUST come from `hard_timeout`, which is the kill deadline in milliseconds. The `timeout` field is the wait in milliseconds before Cursor moves a command to the background, and it MUST NOT become a kill deadline. An MCP frame MUST map to its tool name with its arguments decoded from `google.protobuf.Value`. The idle timer MUST pause while the callback runs, and the client MUST send an exec heartbeat every three seconds. The reply MUST carry the tool output text. A tool error MUST set exit code 1 or the MCP error flag. After the reply, the provider MUST emit `ToolCall{Resolved:true}`. An MCP frame marked approval-only MUST NOT run and MUST be answered as rejected. Without a callback, the provider MUST reply that in-band tool execution is unavailable and MUST NOT emit a tool call. An unknown exec frame MUST be answered with an exec throw. Every exec frame MUST end with an exec stream close.

The provider MUST read server frames while an in-band call runs. An exec-server abort for the running exec MUST cancel the callback context. The provider MUST then send no reply, MUST send the exec stream close, and MUST emit `ToolCall{Resolved:true}`. An abort for a queued exec MUST skip that exec and MUST still send its stream close. Interaction heartbeats during a call MUST be dropped. Other frames that arrive during a call MUST be copied and handled in order after the call. At most 64 frames MAY wait. When 64 frames wait, the provider MUST cancel the callback context and MUST fail the attempt.

The provider MUST answer each interaction query with an interaction response that carries the query id and the matching result field. Web search, mode switch, Exa search, Exa fetch, and web fetch queries MUST be answered as rejected with a reason. An ask-question query MUST be answered with a rejected result. A create-plan query MUST be answered with a plan error. A VM setup query and an unknown query MUST fail the attempt, because their results cannot express a refusal.

Text and thinking updates MUST produce text and reasoning deltas. The turn-ended update MUST produce usage and `Done{stop}` and MUST end the attempt. Turn input usage MUST exclude cache reads and writes. An error trailer MUST fail with the HTTP status of its Connect code. A stream that ends before turn-ended MUST fail with status 503. An attempt that started an in-band call MUST NOT retry. `Models` MUST call `GetUsableModels` and MUST skip empty and duplicate ids.

Cursor conversation state MUST live in the caller's `StateDir`, one directory per thread. The directory MUST hold `conversation-id`, `checkpoint`, and `blobs/<hex id>`. A missing conversation id MUST be created as a random UUID. Files MUST be written to a temporary file and renamed, with mode 0600. An empty `StateDir` MUST use a new conversation id per stream and keep state in memory only.

## Streams

The stream MUST report text deltas, reasoning deltas, complete tool calls, usage, a stop reason, or an error. Tool arguments MUST preserve raw JSON when the provider supplies JSON. A decoder MUST NOT emit partial tool calls. Interleaved calls MUST retain separate ids, names, and argument buffers. Invalid complete JSON arguments MUST fail the stream.

OpenAI reasoning summaries and reasoning text MUST produce reasoning deltas. Anthropic `thinking_delta` blocks MUST produce reasoning deltas. Chat-compatible decoders MUST accept `reasoning_content`, `reasoning`, and `reasoning_text`, in that precedence order. A decoder MUST skip a reasoning field that is not a string and use the next field. Google parts with `thought:true` MUST produce reasoning deltas.

Usage MUST separate uncached input, cached reads, and cache writes. OpenAI and chat-compatible usage MUST subtract cache reads and writes from total prompt tokens. Chat-compatible cache reads MUST prefer `prompt_tokens_details.cached_tokens`, then `prompt_cache_hit_tokens`, then top-level `cached_tokens`, in any key order. Anthropic usage MUST merge non-null fields from `message_start` and `message_delta`. A null field MUST keep the earlier value. Google usage MUST subtract cached content from input and add thought tokens to output.

Stop reasons MUST use `stop`, `length`, or `toolUse`. Provider safety, refusal, unknown, and terminal error reasons MUST fail the stream. OpenAI refusal events and Google `promptFeedback.blockReason` MUST fail the stream. A stream without its required terminal event MUST fail. A stream that emitted a tool call, text, or reasoning MUST NOT retry, because the retry would re-emit the partial content after the failed attempt. A stream failure MUST retain the raw event that caused it.

Google SSE data MAY contain one response object or an array of response objects. Only the first candidate MUST produce events.

When Google returns a function call without an id, or with an id the decoder already saw, the decoder MUST generate an id with a decoder-unique prefix. A first-seen provider-supplied id MUST stay unchanged.

The stream MUST stop when its context is canceled. A consumer MAY use `Next` or range over `Events`. The event queue MUST remain bounded. `Emit` after `Finish` MUST return false and MUST NOT send. An SSE read that ends on cancel, start timeout, or idle timeout MUST close the body and MUST wait for its reader goroutine before it returns. When the reader had already reached a clean end of stream, the read MUST return success.

## Capabilities and roles

`Models` MUST use the provider list endpoint and MUST follow its pagination until the provider reports no further page. Anthropic MUST page with `after_id` set to `last_id` while `has_more` is true. Google MUST page with `nextPageToken`. A repeated page cursor MUST fail. Each capability record MUST include the model id, context window, output limit, effort levels, and tool-choice support when known. Unknown numeric limits MUST remain zero, except for the context default. The context window MUST use the configured value for the bare model id first, then the provider-reported input limit, then 128000. Anthropic MUST read `max_input_tokens`, `max_tokens`, and the levels under `capabilities.effort`. Chat-compatible lists MUST read `context_length`, then `top_provider.context_length`, and `top_provider.max_completion_tokens`. Google MUST read `inputTokenLimit` and `outputTokenLimit` and skip models without `generateContent`. Other list endpoints MUST leave effort levels nil.

Static role presets MUST match the decision table. Providers without a static preset MUST use their first offered model for `smol` and `slow`. An unavailable preset MUST return the thread model and this exact log line: `roles.<name> preset <id> is not offered; using <model>`.

Effort clamping MUST choose the highest supported level at or below the request. It MUST choose the lowest supported level when every level exceeds the request. Nil effort support MUST omit the effort field.

## Retry and timeouts

Transport failures, 408, 429, and 5xx responses MUST be retryable. An HTTP 200 body or stream error with a numeric 429 or 5xx code MUST be retryable. Context-length errors MUST return `Overflow`. 401 and 403 MUST return `Auth`. Usage-limit and other errors MUST be terminal. Transient phrases such as `timeout` MUST be matched only against local transport error text, never against a provider body, so model text inside a refusal cannot cause a retry.

A request MUST retry at most three times. Delays MUST be one, two, and four seconds with plus or minus twenty percent jitter. A valid `Retry-After` value up to 60 seconds MUST replace the delay. With a client attached, a value above 60 seconds and up to 300 seconds MUST wait, and the wait MUST be reported through `dalgona/retry/wait`. A larger value MUST stop the request with `rate limited for <s> s, over the <limit> s wait limit`, where `<limit>` is 300 with a client attached and 60 without one, and `<s>` is the wait rounded up to whole seconds. The error MUST keep the HTTP status and body. The retry callback MUST run before sleeping.

The first-event deadline MUST cover connection, response headers, and the first SSE event. It MUST stop after the first event. The idle deadline MUST measure received bytes. An idle value of zero MUST disable the idle deadline. The idle controller MUST support pause and resume for in-band tool execution. Timeout failures MUST be retryable. Errors MUST retain HTTP status and raw provider error bodies when available.
