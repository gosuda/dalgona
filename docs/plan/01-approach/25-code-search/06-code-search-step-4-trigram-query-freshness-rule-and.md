  - `type trigramFilter struct { manifest manifest; all bool; named map[string]bool; clock freshness }`.
  - `func openTrigramFilter(dir, pattern string, clock freshness) (*trigramFilter, error)`. An empty `dir` returns nil and no error. When the file `manifest` or the file `trigram` in `dir` does not exist, it returns nil and no error, so a generation deleted during the call acts as no index. Otherwise it reads `manifest` with `readManifest`. A failure returns an error that wraps `errIndex`. When the size of `trigram` differs from `TrigramSize`, it returns an error that wraps `errIndex` with the reason `trigram size`. It calls `index.Open`, which can exit the process on corruption (`index/read.go:100`). It parses the pattern with `syntax.Parse(pattern, syntax.Perl)` and passes the result to `index.RegexpQuery`. A query with `Op == index.QAll` sets `all`. Any other query fills `named` with `Name(id)` for each id from `PostingQuery`. A deferred recover turns a panic into an error that wraps `errIndex`.
  - `func statMatches(rec manifestEntry, info fs.FileInfo) bool`: `Size`, `ModNS` and `CtimeNS` equal the values of `info`. The change time is read with `ctimeNS`, and a missing change time makes the result false.
  - `func settled(rec manifestEntry, info fs.FileInfo, m manifest, clock freshness) bool`: `ctimeSupported` holds, `clock.Now >= m.Start`, `statMatches` holds, and both `rec.ModNS` and `rec.CtimeNS` are less than `m.Start - clock.Racy`.
  - `func (f *trigramFilter) decide(display string, info fs.FileInfo) (read, counted bool)`: finds the record with `manifest.lookup`. When the record exists, `Indexed` holds, and `settled` holds, the file is covered: it is read when `all` holds or `named[display]` holds, and it is not counted. Otherwise the file is read. It is not counted when the record exists, `Indexed` is false, and `statMatches` holds (decision 13). In every other case it is counted.
  - `func planReads(files []fileEntry, filter *trigramFilter) ([]fileEntry, int)`: for each file, calls `os.Lstat(file.absolute)`. It skips the file when the Lstat fails or `searchableInfo` does not hold. When the filter is nil, the file is read and counted. Otherwise it takes the result of `decide`. It keeps the read files in their order and returns them with the sum of the sizes of the counted files.
  - `func execute(cwd string, args args, dir string, clock freshness) (outcome, error)`: the scope and walk are unchanged. Find mode calls `find(entries, args)`, which ignores `dir` and `clock`. Grep mode calls `grep(entries, args, dir, clock)`.
  - `func grep(entries []fileEntry, args args, dir string, clock freshness) (outcome, error)`: calls `grepRegexp(args)`, then `matchingFiles`, then `openTrigramFilter(dir, grepPattern(args), clock)`, then `planReads`, then `collectMatches`, then `renderGrep`. It sets `Unindexed` on the result. Errors from the filter are returned unchanged.
  - `func grepPattern(args args) string`: applies `regexp.QuoteMeta` when `literal` holds, and then the prefix `(?i)` when `ignore_case` holds. `grepRegexp` compiles this string, so one code path builds the pattern.
  - `func parseIndexArgs(argv []string) (dir string, clock freshness, err error)`: `argv` holds the root, the generation name, the now value in nanoseconds and the racy value in nanoseconds. The generation name is one path element and is not `.` or `..`. The two values parse as decimal integers. `dir` is `filepath.Join(root, gen)`.
  - `func Main(argv []string, stdout io.Writer) int`: one argument, the JSON, or five arguments, the JSON followed by the four index arguments. Any other count writes the usage line `usage: __search <json-arguments> [<root> <generation> <now-ns> <racy-ns>]` and returns 2. With five arguments, `parseIndexArgs` gives the directory and the clock. An error that wraps `errIndex` writes its text to stdout and returns `indexFailedStatus`. Any other error writes its text to stdout and returns 2. A failed write to stdout returns 2.

- Spec, in the section `## Index` of `docs/spec/search.md`. Each sentence has at most 25 words and no semicolon.
  - A grep call with an index MUST return the same output as a grep call without one.
  - The index MUST let the search skip a file only when its trigram query cannot match the file.
  - A file MUST count as covered only when its size, modification time and change time equal its manifest record.
  - A covered file MUST have both times more than 2 seconds older than the build start.
  - The search MUST read every file when its clock is earlier than the build start.
  - A file without a covering record MUST be read as it is without an index.
  - A file that the last build did not index MUST NOT count toward the build threshold while its stat is unchanged.
  - The find mode MUST NOT use an index.
  - The search child MUST exit with status 1 only when the index is unusable.
  - The search child MUST treat a generation deleted during the call as no index.
  - The search child MUST write nothing to standard error when it succeeds.
  - The search MUST NOT show the unindexed byte count to the model.
