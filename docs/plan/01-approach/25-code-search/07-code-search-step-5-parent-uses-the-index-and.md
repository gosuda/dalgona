- Spec, in the section `## Index` of `docs/spec/search.md`:
  - Search MUST use an index only for grep calls, only with a local runner, and only when the sandbox enforces its writable roots.
  - Search MUST NOT read or build an index when the sandbox is off or the runner cannot enforce it.
  - The index root MUST be the product home, plus `search`, plus a 16-digit hash of the canonical workspace path.
  - Search MUST NOT use an index when the index root lies inside the workspace, the temp directory, the user cache or a writable root.
  - Search MUST pass the index root, the generation name, its clock and the racy window to the search child as arguments.
  - The model MUST NOT be able to choose the index root or the generation.
  - After exit status 1, Search MUST remove `CURRENT` only when it still names the failed generation.
  - Search MUST run the same call again without an index, under a new process id.
  - Search MUST log an index failure at warn level, and the model MUST NOT receive it.
