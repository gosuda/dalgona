#### Decisions of the comment-removal workstream

1. What counts as a prose comment. Go: each comment token, standalone or trailing, that the allow list of Step 21 does not match. TypeScript and Svelte: a line whose first non-blank characters are `//` or `/*`, and in Svelte also `<!--`. Python: a line whose first non-blank characters are `#` (except `#!` on line 1) or `"""`. Rival: godoc comments only. Reason: the owner rule covers every explanatory comment, and a rule that skipped trailing comments would leave some behind.
2. Allowed directives. The gate allows four Go forms and no others: `//go:build`, `//go:embed`, `//go:generate` and `//nolint:<linters> // <reason>`. Rivals: allow `//lint:`, `//export` and a generated-code header (CEO review), overruled because the owner fixed the four forms and the tree holds none of the others; move `//nolint` reasons to tests (rival), overruled because a reviewer reads the reason on the line where a finding is suppressed. Grep of `*.go` on 2026-11-12 found no `//go:` form other than `build` and `embed`, no `//nolint` without a reason, and no `//lint:`, `// +build`, `//line` or `//export` line. No Python, TypeScript or Svelte directive form exists, so the gate allows none, and its failure message tells the author to restructure.
3. Where knowledge goes. A rule the code shows is deleted, and its name, type or body is the home. A rule the code does not show gets one sentence in the topic file under `docs/spec`, in the commit that deletes the comment. Rivals: `docs/decisions` (gives a reason, not the behaviour) and a test (shows a rule without stating it). Reason: the owner rule names `docs/spec`.
4. Sentence form. Each new sentence has at most 25 words, no semicolon, no em dash and no lower-case `should`, and it uses MUST in its RFC 2119 sense. Rival: keep the citations in code, as `CONTRIBUTE.md` line 11 allows today. Overruled: the owner rule takes every prose comment out of the source, and the spec holds the citation.
5. Upstream names. A spec sentence names an upstream project and a path inside it, for example `pi`'s `packages/ai/src/...`. It never names a `.references/` path, because `.references/` is git-ignored (`.gitignore`) and absent from a clean clone. Rival: quote the local path. Reason: a sentence must read correctly in every clone.
6. Rename. `rules.CheckValue` becomes `rules.CheckRemoteValue` in Step 3: the definition at `internal/agent/rules/rules.go:165`, the one caller at `internal/agent/gate.go:154`, and the doc comment at `rules.go:164`, which goes in the same commit. Rival: rename `remote.Box` to `UnboundBox` (row 5). Rejected: the plan keeps the name `Box`.
7. Archive order. The `runners.md` sentence states the order the code runs. `Host.Archive` journals `thread.archived` first (`internal/rpc/serve_thread.go:540`). Then the archive hook runs: `ServeOptions.BeforeArchive` is `batteries.Archive` (`cmd/dalgona/daemon.go:65`), which calls `(*Binder).Archive` (`internal/app/battery/battery.go:80-81`). The server calls `Host.Unarchive` when the hook fails (`serve_thread.go:551`). Rival: move the hook before the journal entry. Rejected: that changes behaviour, and this workstream changes none. The outcome holds because `otherUser` in `internal/remote/lifecycle.go` skips the thread itself.

The caller refuses on an error unless the reply is cancel (`cmd/dalgona/daemon.go:81-82`), and a cancel leaves the session unpoisoned. The spec states the caller rule. Rival: keep the comment. Rejected: it is false as written.

12. Gate mechanism. A Go test in the new package `internal/commentgate`. The `test` recipe runs `go test -race -count=1 ./...` (`justfile`), and `verify` runs `test`, so `just verify` runs the gate with no recipe change. Rivals: a golangci-lint or Biome rule (none rejects prose comments: gocritic `commentedOutCode` checks code, and Biome `noCommentText` ignores real comments), a justfile grep (flags `//` inside strings), a Vitest test (covers `web/` only), and a tree-sitter binding (a new module). Reason: standard library only, exact for Go, and it runs in the existing recipe.

No trailing comment exists in those files: a grep finds no `//` after code in `.ts` or `.svelte`, and the only `#` in `.py` starts a line. Rival: a tokenizer per language. Rejected: none exists in the repository, and a parser needs a dependency decision.
