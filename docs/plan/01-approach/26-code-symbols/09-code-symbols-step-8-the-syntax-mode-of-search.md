- The search mode. `syntax` runs the query `pattern` on every file whose extension selects the language named by `lang`, including syntax-only languages. The walk, the caps, the per-file rules, the budgets and the footers are those of Step 6. Each capture row is `PATH:LINE: CAPTURE: TEXT`. `TEXT` is the source from the capture's start byte to its end byte, cut at the first newline and then cut by `cropMatch`. Rows sort by path, then line, then column, with columns in bytes counted from one. `limit` caps the capture rows, with a default of 200 (`json.go:88`). When the cap cuts rows, the last line is `[Truncated: N more captures]`. Syntax mode returns no capture records, so no snapshot tags are added (decision 17). With no captures the reply is `No matches for PATTERN. Searched N files of language NAME.`

- Specification text, in `docs/spec/search.md` under `### Syntax`:
  - The syntax mode MUST run a tree-sitter query on each file of the language named by `lang`.
  - A query that does not compile MUST return the library message after the prefix `syntax: `.
  - Each capture row MUST show the file, the line, the capture name, and the captured text.
  - The `lang` argument MUST be set in the syntax mode, and it MUST NOT be set in any other mode.
  - The syntax mode MUST NOT carry snapshot tags.
