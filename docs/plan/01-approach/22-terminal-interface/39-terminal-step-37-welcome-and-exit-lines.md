#### Terminal step 37. Welcome and exit lines
Anchor: J.R.R. Tolkien, Saul Bass

- The `initialize` result reaches the model in Step 12, which owns its `applyResult` case and the fields `m.conn.product` and `m.conn.version`. This step only reads those fields.
- Welcome: the `initialize` case commits the key `welcome` once, on success and on error. On success the row holds the two lines that follow. On error the row's first line is `Could not start: <error>. Press ctrl+c to exit.`, cut with `fit`. The row is always committed, so the view never stays empty. The two lines are `<product> <version> · <model> · <cwd>` and `Type a prompt · / commands · ? keys`. The model is `m.thread.modelName`, or `default` when it is empty. The cwd is `m.conn.opts.Cwd` with a leading `$HOME` shown as `~`. The welcome row uses only the default foreground, bold and dim. The product name is bold, and the rest is dim. It adds no mascot text (Design record, Product marks). Welcome runs at start, before the first thread's rows (`Init` at `model.go:139-142` sequences `initialize`, `loadKeywords`, then `startThread`).
- Quit: This step adds the exit line to `quit()`, which Step 13 defines and Ctrl+C calls. Every other path that returns `tea.Quit` calls it too. `quit()` calls `closeReview` (Step 15), sets `m.leaving` and `m.quitting`, and calls `m.commit("exit", []string{line})`. The leaving view is one row. The frame changes, so the exit print waits for the settled frame (print rule 2). `drain` prints the rows that waited and then the exit row, one chunk at a time, with the leaving view frozen (print rule 3). `finishQuit` returns `tea.Quit` after the last `printedMsg` (Step 13). An open review closes first, and its waiting rows print before the exit row (Structure). The line is `Thread <title> saved · resume with <product> --resume <id>`, or `No thread was started` without a thread.
- Leaving view: while `m.leaving` is set, `View` returns one line that holds one space, and sets `view.ProgramStatus = &tea.ProgramStatus{State: tea.ProgramStateIdle}` (`bubbletea/v2@v2.1.1/tea.go:161`, the field; `programstatus.go:22`, the constant `ProgramStateIdle`). The renderer erases from the last row of the last view, so the last view is never empty (`cursed_renderer.go:201-206`: the cursor moves to the last row, then the rest of the screen is erased). `m.leaving` is set in the update that starts a quit or a suspend. `ctrl+z` calls `suspend()` (Step 13), which sets `m.leaving` and `m.suspending` the same way, and `tea.ResumeMsg` clears `m.leaving` (Bubble Tea practice rule 19).
- Symbols that change: `quit` (Step 13, gains the exit line), `suspend` and `finishSuspend` (Step 13), `View` (leaving branch), `leaving` and `suspending` (declared in the Structure, set in Step 13 and here).
