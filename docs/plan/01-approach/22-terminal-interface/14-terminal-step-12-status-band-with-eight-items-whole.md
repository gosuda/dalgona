#### Terminal step 12. Status band with eight items, whole-item dropping and icons

- `band.go`: `type segment struct{ id, text string; rank int }` (`id` is an Design record, Status band item id; `rank` is the drop order: `folder` 1, `queue` 2, `effort` 3, `mark` 4; `model`, `context`, `approval` and `sandbox` have rank 0 and never drop), `func renderBand(left, right []segment, width int) string`. The band is one row of fixed fields. The row is at most `width - 1` cells (I6).
- Places (Design record, Status band). The left group starts at column 0 and holds `model`, `effort`, `approval`, `sandbox`, `folder` and `queue`. The right group sits flush at the right edge and holds `context` and `mark`. One space separates items. One space separates the two groups.
- Fields and cell widths. The widths below are fixed. A glyph takes the width given here, not the width `cells` reports, because `cells` counts a private-use Nerd glyph as two cells.
  - `model`: the model name as text, free text. Passes through `fit(name, n)`.
  - `effort`, `approval`, `sandbox`: one glyph each, 1 cell.
  - `folder`: one glyph, one space, then the folder name, free text. Passes through `fit(name, 16)`. Unicode glyph U+25B8 (cross-phase decision 58), one space after it. Nerd glyph U+F0256.
  - `queue`: `+` and the count right-aligned in 3 cells, 4 cells in total. `fmt.Sprintf("+%3d", n)` gives `+  1` and `+ 32`. `maxFollowups` is 32 (`internal/tui/commands.go:21`), so the count fits the field. Nerd: glyph U+F051F, one space, then the same 4-cell field.
  - `context`: the percent right-aligned in 4 cells. `fmt.Sprintf("%3d%%", pct)` gives ` 25%`, `100%` and `  5%`. Unicode: 4 cells. Nerd: moon glyph, one space, then the 4-cell field, 6 cells in total.
  - `mark`: the product name, free text. Passes through `fit(name, n)`. Its colours come from Design record, Status band.
  - Free text in this row always passes through `fit`. A grapheme is never split.
- Empty items. Items named in `statusHide`, and items with no value, are removed before layout: context with a zero window, queue when empty, effort when hidden.
- Layout. Let `L` be the width of the left group and `R` the width of the right group, both in the fixed widths above. The row fits when `L + 1 + R <= width - 1`. While it does not fit, drop the ranked item with the lowest rank number above 0 that is still present. When no ranked item is left and the row still does not fit, cut the `model` text with `fit` to the room left. If the fixed fields alone still do not fit, cut the whole row with `fit(row, width - 1)`.
- Items and their text, icons from table T2. `model` is the model name as text and cannot be hidden. `effort` is one icon by rank (Design record, Icons): the glyph index is `round(rank * 3 / (levels - 1))` over the model's own levels. The item is hidden when the model has fewer than two effort levels, or when the current effort is not one of its levels (cross-phase decision 15). `approval` is one icon for `thread.approvalMode` (`ask`, `auto`, `yolo`).
- `sandbox` is one icon for `workspace-write` or `off`. Config `off` and the wire value `dangerFullAccess` both mean sandbox off (`internal/rpc/serve_thread.go:99`). The server parses `dangerFullAccess` back to `off` at `internal/rpc/serve_turn.go:73-74`. `serverSandbox` maps `dangerFullAccess` to `off` (`internal/tui/commands.go:593-594`) and `readOnly` to `workspace-write` (`commands.go:597-598`). The config accepts only `workspace-write` and `off` (`internal/config/merge.go:402-403`). `folder` is one icon, as above. `queue` is the icon and the count of `m.queue`, shown only when the queue is non-empty.
- `context` is the moon gauge and the percent, hidden when the window is 0. Unicode shows the percent alone. Context used is `Last.InputTokens + Last.CachedInputTokens + Last.CacheWriteInputTokens + Last.OutputTokens` (`ThreadTokenUsage` at `internal/rpc/types.go:223-226`; `TokenUsageBreakdown` fields `inputTokens`, `cachedInputTokens`, `cacheWriteInputTokens` and `outputTokens` at `types.go:228-233`). The fraction is used divided by `usage.ModelContextWindow` (`types.go:226`), clamped to 0 to 1. The percent is `round(f * 100)`. The Nerd moon index is `round(f * 14)`. No `round(f * 4)` index exists in Unicode.
- `mark` is the product name in the Design record, Status band colours, hidden until `initialize` has set `conn.product`. `applyInitialize` is not in the tree (`grep` in `internal/tui` finds no definition).
- The `initialize` result reaches the model here, because this step needs `conn.product`. `initialize` (`commands.go:52-66`) returns the decoded `rpc.InitializeResult` as the value of its `resultMsg`: `resultMsg{op: "initialize", value: &result, err: m.client.Notify("initialized", nil)}`. `applyResult` gains an `initialize` case. Step 37 keeps only the welcome row and the exit line.
- `apply.go`: handle `thread/tokenUsage/updated` for the followed thread (`internal/rpc/types.go:218-222`) into `thread.usage`. `applyNewThread` (`commands.go:578`) and `applyResumed` (`commands.go:557`) set `thread.effort` from `ThreadStartResponse.ReasoningEffort`, and `applyResumed` sets no usage, because `ThreadStartResponse` (`internal/rpc/types.go:75-83`) has no token member; `thread.usage` fills from `thread/tokenUsage/updated` alone. `applyConfig` (step 9) uses `model_reasoning_effort` as the fallback.
