#### Terminal step 9. Themes, no-colour mode and background detection

- `theme.go`: `type role int` with `roleText, roleDim, roleFaint, roleAccentText, roleFailedText, roleAddedText, roleWarningText, roleCount`. These are the terminal text roles of Design record, Colour: `faint` is for panel rails only, `accent-text` for the keyword mark, links and the name `dalgona`, `failed-text` for the word Failed, error text and deleted diff lines, `added-text` for added diff lines, and `warning-text` for Offline and for warnings. `type themeName string` with `day`, `soft-day`, `night`, `soft-night`. `func resolveTheme(setting string, dark bool) themeName` maps `auto` to `night` or `day`, `auto-soft` to `soft-night` or `soft-day`, and an explicit name to itself. `var palettes map[themeName][roleCount]string` and `var hues map[themeName][4][2]string` (point and on-point colour per hue index) hold the values of table T1. `func threadHue(threadID string) int` is FNV-1a 32-bit over the UTF-8 bytes of the id, modulo 4 (`hash/fnv` `New32a`); the empty id is valid and gives the hue before a thread exists.
- `type theme struct{ name themeName; known, color bool; styles [roleCount]lipgloss.Style }`. `func newTheme(name themeName, color bool) theme` sets `known` to true. The zero `theme` is not known. `func (t theme) paint(r role, s string) string` works in three cases. When `known` is false, `roleDim` gives dim (SGR 2), `roleAccentText` and `roleFailedText` give bold (SGR 1), and every other role returns `s` unchanged. When `known` is true and `color` is false, a style keeps only Bold, Underline and Reverse. When `known` is true and `color` is true, the role colour applies. `func (t theme) liveTag(hue int, s string) string` fills `s` with the point colour `hues[t.name][hue][0]` and sets the text to the on-point colour `hues[t.name][hue][1]`. With `color` false it uses Reverse plus Bold. The point is the only background the terminal draws: with colour off it is reverse video, and no other cell has a background. The failed word is never a fill: it is bold in `failed-text`.
- `func (s *screenState) setTheme()` sets `theme = newTheme(resolveTheme(themeSetting, dark), color)` when `themeSetting` is explicit (not `auto` or `auto-soft`) or when `hasDark` is true. `func (s *screenState) dockTheme() theme` returns `theme` when it is known. Otherwise it returns `newTheme(resolveTheme(themeSetting, true), color)`, which is `night` or `soft-night` until the background reply arrives (decision 7 of this workstream). The dock draws with `dockTheme`. `commit` paints rows with `theme`.
- Written rows keep the colours they were painted with. Before the theme is known, rows use only the default foreground, bold and dim (design: colours that cannot be taken back). A theme change through `/settings` never rewrites a printed row. Only later rows use the new theme.

- `theme.go`: `func (s *screenState) emit(text string) string` returns `text` with its colours converted to `s.profile`: `var buf strings.Builder; w := colorprofile.Writer{Forward: &buf, Profile: s.profile}; _, _ = w.WriteString(text); return buf.String()` (`colorprofile@v0.4.3/writer.go:32-35, 37-50`). `Writer.Write` passes `TrueColor` through, strips every sequence at `Unknown` and `NoTTY`, and rewrites SGR colour for `ASCII`, `ANSI` and `ANSI256`, which keeps bold, underline and reverse. `screen.profile` therefore starts as `colorprofile.ASCII`, not the zero `Unknown`, which would strip bold as well. `View` and `drain` both pass their output through `emit`.
- `markdown.go`: `type mdKey struct{ width int; theme themeName; color bool }`. `func markdownStyle(t theme) ansi.StyleConfig` copies `styles.DarkStyleConfig` (night, soft-night), `styles.LightStyleConfig` (day, soft-day) or `styles.NoTTYStyleConfig` (no colour). `ansi.StylePrimitive.Color` is a `*string`, so each palette hex value is passed by address. It overrides `Document.Color` with text, `Heading.Color` with text plus bold, `Link.Color` and `LinkText.Color` with accent-text, and `Code.Color` with text. The renderer uses `glamour.WithStyles`.
