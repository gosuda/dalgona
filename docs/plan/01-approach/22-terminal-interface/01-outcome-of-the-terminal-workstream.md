#### Outcome of the terminal workstream

When this workstream is done, the user works in an inline dock (a live row while working, a multi-line editor, one status band) above native scrollback. Each finished item is printed once as a readable row at the chosen verbosity. `ctrl+o` opens the full text in a full-screen review. Every slash command opens a bounded panel with keyboard navigation and a way back. Approvals and questions always show their title and action row at any window size, and no untrusted text can reach the terminal unsanitised. Six theme settings (four themes and two auto modes), a status band with icons and optional hidden items, a no-colour mode, `NO_COLOR`, `DAL_NO_MOTION`, notifications, the window title, and the welcome and exit lines all work with their defaults.
