#### Terminal step 2. One sanitiser for all untrusted text

- `sanitize.go`: add `func appendSanitized(dst, src []byte) []byte`, which works like `sanitizeText` (`render.go:52-70`) and also drops the bidi controls U+061C, U+200E, U+200F, U+202A to U+202E and U+2066 to U+2069, plus the private-use runes U+F0000 to U+FFFFD (reserved for chips in step 28). `sanitizeText` becomes a wrapper over `appendSanitized`. This function sees untrusted input only. The glyphs the client draws (step 12, including the Nerd glyphs at U+F0000 and above) never pass through it.
- `width.go` (new file): the three methods on `screenState`, `cells`, `fit` and `wrap`, defined here. Each applies `norm.NFC.String` (`golang.org/x/text/unicode/norm`) first, so text is NFC before it is measured or cut. `cells(text)` returns `s.method.StringWidth(nfc)`. `fit(text, n)` returns the NFC text when `cells(text) <= n`; otherwise it returns `s.method.Truncate(nfc, n, "...")`, and when `n` is below 3 it returns `s.method.Truncate(nfc, n, "")`. `wrap(text, n)` splits `s.method.Wrap(nfc, n, "")` at its newlines (`x/ansi@v0.11.9/method.go:37-100`). `ansi.Method` has the values `ansi.WcWidth` and `ansi.GraphemeWidth` (`method.go:33-34`). `screen.method` starts as `ansi.WcWidth`. A grapheme is never cut.
- Measure follows the renderer, with no rule of this client (cross-phase decision 57). An East Asian Ambiguous rune is 1 cell, as the library counts it, and `RUNEWIDTH_EASTASIAN=1` changes the count for both the renderer and the client (`x/ansi@v0.11.9/method.go:21`). No character is replaced with `?`.
