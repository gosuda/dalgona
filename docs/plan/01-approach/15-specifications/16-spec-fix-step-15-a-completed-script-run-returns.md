#### Spec-fix step 15. A completed script run returns its recorded outcome
Anchor: Tony Hoare, Richard Feynman

The text is right and the code breaks it. `docs/decisions/starlark-replay.md` line 7 says: "A completed run MUST return its recorded outcome." Keep that sentence. `docs/spec/starlark.md` line 46 states the rule of the code, so this step also changes that sentence.

- Defect: a crash after `script.completed` and before `tool.completed` leaves the tool call in flight. Recovery calls the tool again with the same call id (`internal/agent/recover.go:157-161`, `docs/spec/recovery.md:40`). `effects.Started` finds the start record of the turn, sees that the run is not open, and returns `scripthost: duplicate run id <id>` (`internal/scripthost/effects.go:126-129`). `Eval.Run` wraps that error (`internal/script/eval.go:85-88`), so the model reads an error in place of the recorded result.
- Rule: a start whose run id has `script.completed` in the open turn returns the recorded outcome when the request has the same entry point, source, and argument bytes as the recorded start. The engine does not run the source again. A different request with that run id still fails as a duplicate run id, so `TestReusedRunIDWithinTurnIsRefused` (`internal/scripthost/effects_runid_test.go:29-42`) stays as it is: its two calls share the call id `e` and have different code (`internal/scripthost/harness_test.go:65-68`). A run id from a prior turn still starts fresh.
- Interface: `internal/script/effects.go:56`, in `Journal`, becomes `Started(start RunStart) (RunStart, *Outcome, error)`. A non-nil `*Outcome` means that the run completed earlier in this open turn. The caller returns it and does not run the body.
- Callers: `internal/script/eval.go:85-88` `Eval.Run` adds `if done != nil { return replyResult(call.ID, *done) }` after the error check. `internal/script/plugin.go:186-189` `Plugins.invoke` adds `if done != nil { return *done, nil }`. `internal/script/workflow.go:17-20` `RunWorkflow` adds the same line. The test fake at `internal/script/journal_test.go:39-47` returns a nil outcome on both of its paths.
- `internal/scripthost/effects.go:121-144` `effects.Started`: keep the `fx.idx.start` lookup. For an open run, return `fx.pinned(started)` with a nil outcome, as now. For a run that is not open, do these checks in order.
  1. `done, ok := fx.idx.completed(records, start.ID)`. When `ok` is false, return the error `scripthost: duplicate run id %s`, as now.
  2. `pinned, err := fx.pinned(started)`. Return `err` when it is not nil.
  3. When `pinned.Entry != start.Entry`, or `!bytes.Equal(pinned.Source, start.Source)`, or `!bytes.Equal(pinned.Args, orNull(start.Args))`, return the error `scripthost: duplicate run id %s`, as now. Effect replay hashes the raw argument bytes and compares the digests (`internal/script/effects.go:93-96`, `internal/script/run.go:181`), so byte equality is the rule there too.
  4. Otherwise return `script.RunStart{}`, the outcome that `fx.recordedOutcome(done)` rebuilds, and nil. A load error is wrapped as `scripthost: outcome of %s: %w`.
- Completion lookup: `effectCache` gains the field `completions map[string]event.ScriptCompleted`. `newEffectCache` (`internal/scripthost/effects.go:53-58`) makes it. `ensureTurn` (`effects.go:79-87`) resets it with the other maps. `observe` (`effects.go:200-222`) adds `case event.ScriptCompleted: c.completions[value.RunID] = value`. `func (c *effectCache) completed(records []event.Seqd, run string) (event.ScriptCompleted, bool)` mirrors `start` (`effects.go:224-234`). For a nil cache it scans `scopedRecords(records)`, as `scanStart` does (`effects.go:236-243`).
- `func (fx effects) recordedOutcome(done event.ScriptCompleted) (script.Outcome, error)` is new. When `done.OK` is true it returns `script.Outcome{Status: script.StatusCompleted, Value: value}`, where `value` comes from `fx.t.LoadRaw(done.Value, done.ValueBlob)` (`internal/agent/extension.go:67-69`). When `done.Status` is empty, which marks an old record, it returns `script.Outcome{Status: script.StatusFailed, Error: script.Failure{Message: done.Error}}`. Otherwise it returns `script.Outcome{Status: script.Status(done.Status), Error: script.Failure{Code: done.Code, Message: done.Error, Stage: done.Stage}}`, so a limit, a denial, a cancellation, and an indeterminate end keep their status. `ScriptCompleted` (`internal/agent/event/event.go:561-567`) gains the string members `Status`, `Code`, and `Stage`. The codec in `internal/agent/event/codec.go` reads and writes each one only when it is set. `Completed` (`internal/scripthost/effects.go:321-339`) writes `outcome.Status`, `outcome.Error.Code`, and `outcome.Error.Stage`, and keeps `done.Error` as the message. A record without `Status` is an old record. `recordedOutcome` rebuilds it as the next rule says, so an old journal stays readable. Prints are not recorded, so the rebuilt outcome has none.
- Specs, in the same commit. `docs/spec/starlark.md:19`: write the new signature. `docs/spec/starlark.md:46`: replace "A known run id that completed earlier in the same open turn MUST fail as a duplicate run id." with "A known run id that completed earlier in the same open turn MUST return its recorded outcome when the request has the same entry point, source, and arguments. The engine MUST NOT run the source again. A different request with that run id MUST fail as a duplicate run id. The recorded outcome has the status that the run ended with. A completed run has the value. A failed or stopped run has the code, the message, and the stage. It has no prints." `docs/spec/recovery.md:40`: after "an interrupted effect ends the run with status `indeterminate`.", add "A run that already has `script.completed` returns its recorded outcome, and the engine does not run the source again."
