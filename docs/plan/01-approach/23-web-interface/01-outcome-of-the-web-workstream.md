#### Outcome of the web workstream

In the browser, a user can run a whole thread end to end: start or open a thread, stream Markdown answers with highlighted code, read tool cards, diffs, the plan and subagents, answer approvals and questions without losing sight of the actions, and queue, steer or interrupt work from a docked composer. Every slash command opens a panel with keyboard navigation and validation on submit: model and presets, settings (theme, verbosity), login, resume, tree, rewind, fork, compact, advisor and review. The page uses the shared visual system: six theme settings (`auto`, `auto-soft`, `night`, `soft-night`, `day`, `soft-day`), self-hosted Bricolage Grotesque, Hanken Grotesk and Pretendard, the reader's own monospace, plain state words, one breathing dot, and one point per view in the open thread's hue. Nerd icons come from a subset font that the browser draws. It works at 320 px, under forced colours and reduced motion, by keyboard alone, and with screen readers that no longer receive one announcement per streamed delta. Every parser is checked against the vendored Codex schema, and thread status honours the `seq` guard.
