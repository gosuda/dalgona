### Cross-phase decisions

These decisions bind more than one workstream. A step may cite one as `cross-phase decision N`. They win over the text of a step.
#### Server side

1. Device-code login uses the existing provider id `chatgpt`. No provider is renamed.
2. Anthropic `redacted_thinking` replay keeps the order the core-fixes workstream chose. Contingency: if a live call returns HTTP 400 for the replayed request, send the blocks in their original order. The live call is an external check.
3. Windows pinned writes: whether an open `os.Root` handle blocks a rename of the directory is an external check on a Windows host. Contingency: if it blocks, open the root for each write and close it after the write.

42. One diff package. One package `internal/textdiff` serves every caller: `type Stats struct { Added, Removed int }`, `const Limit = 1 << 20`, `func Unified(oldName, newName string, pre, post []byte, context int) (string, Stats, error)`. Equal inputs return `""`, `Stats{}` and a nil error. Every caller passes 3 for `context`, except the turn unit of the edit review, which passes 0. It is built on `github.com/aymanbagabas/go-udiff v0.4.1`: `udiff.ToUnified(oldName, newName, string(pre), udiff.Lines(string(pre), string(post)), context)` returns the text with `context` lines of unchanged text around each hunk (`unified.go:36`), and it writes `\ No newline at end of file` itself (read in `unified.go:22` and `unified.go:261` of that version). `Stats` counts the hunk lines that begin with `+` or `-` after the two header lines. The module is added to the require block of `go.mod`, and `docs/decisions/dependencies.md` gains its row (licence BSD-3-Clause and MIT, latest version on the proxy on 2026-11-11, repository pushed on 2026-11-10). `github.com/hexops/gotextdiff` is not used: it has had no release since 2020 and accepts no change of its own. No hand-written Myers code. `internal/rpc` and the edit-review hook both call `textdiff.Unified`; a side above `textdiff.Limit` is not diffed (the server sets `DiffOmitted`; edit review skips the file). Tests check this package's own work, not the library: `TestUnifiedCountsAddedAndRemovedLines` (hand-counted cases, for example `a\nb\nc\n` to `a\nx\nc\nd\n` gives `Stats{Added: 2, Removed: 1}`), `TestUnifiedCountsLinesThatStartWithDashes` (a removed line `--- x` and an added line `+++ y` each count once and the two header lines count zero), `TestUnifiedDoesNotCountTheNoNewlineMarker`, `TestUnifiedEqualInputsReturnEmpty`.
