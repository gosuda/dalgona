- Settled fact: the provider limits on tool names are these. OpenAI Chat Completions requires a-z, A-Z, 0-9, underscores and dashes, with a maximum length of 64 (https://platform.openai.com/docs/api-reference/chat/create). Anthropic requires `^[a-zA-Z0-9_-]{1,128}$` (https://platform.claude.com/docs/en/agents-and-tools/tool-use/define-tools). Gemini function declarations require a-z, A-Z, 0-9, underscores, colons, dots and dashes, with a maximum length of 128 (https://ai.google.dev/api/caching#FunctionDeclaration). The character set in the rule above fits all three, and the 64 limit is the smallest, so `maxToolName` stays 64. The output is ASCII, so bytes and characters match.
