# Stabilize and complete dal and dalgona

## Context

The owner asked for one pass that stabilizes and completes both products of the Go module `github.com/gosuda/dalgona`: `dal` (the minimal agent) and `dalgona` (the agent with batteries). The pass debugs the terminal interface and the web interface live, end to end, and raises the design and the function of both. It ports the good parts of `.references/omp2`, `.references/oh-my-pi` and `.references/grok-build`, and it learns from `.references/crush` without copying code.

During planning the owner added: an `ask` tool; verbosity levels; interactive `/settings`, `/login`, `/model`, presets and slash commands; an opt-in review of each edit and each turn by a decision model, on many dimensions; a `ratchet` tool; `DESIGN.md` and a grounded `AGENTS.md`; four themes; a colour for each thread; a status band with icons; new product marks; the removal of wrappers that hide nothing; a correction of every file under `docs/` against the code and a rewrite of `docs/spec` in ASD-STE100; current Bubble Tea practice; a terminal screen that never shakes and is never drawn again, designed from first principles; and a check of every version pin on 2026-11-11.

On 2026-11-12 the owner added: an edit review that splits a large edit into several requests by itself; a print path for the terminal that is judged on evidence; an indexed `grep` built on `github.com/google/codesearch`; symbol lookup, definition reading and syntax queries as modes of the `search` tool, and a structural rewrite tool, all on `github.com/odvcencio/gotreesitter`; `eval-first` as the default tool mode of both products, with every tool except `eval`, `yield`, `ask` and the `approve` action of `ratchet` callable from a script cell; and the removal of every prose comment from the source.

The plan ends in this state. Every command and integration that `README.md` and `docs/spec` describe works as described, except the outside checks that a host cannot run. Those checks read `Not proven` in the report. `just verify` passes. Both interfaces pass the live sessions that this plan scripts. No statement under `docs/` contradicts the code, and `docs/spec` passes the style check that this plan adds. That check covers sentence length, semicolons, em dashes and lower-case `should` only. A reviewer checks the other rules of rule 3 by hand.

The repository was read at commit `3c4b6f94` with a clean working tree. Line numbers in this plan are hints from that commit. Read each file again before you edit it.
