# dalgon serve: the model router and A2A

Loopback only; `--public` stays on loopback and requires `dalgon serve token` for remote clients arriving through a trusted HTTPS/WSS reverse proxy on the same host. Routes pick model ids; continuation resumes sessions; errors name the fix. `[serve] approval` gates router actions. A2A with `--a2a` serves the agent card and methods.
