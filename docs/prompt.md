# The system prompt

Section order: identity, diagrams, tools, skills, rules, rulebook, plugins, environment, instructions, fallback, docs line.

The labeled `AGENTS.md` walk: instruction context, never a deterministic permission boundary. `SYSTEM.md` adds user text. Skill descriptions appear in the prompt or as a letter. Letters carry long stable text as images; the exact text stays readable at `letter://<id>`. The manual line lists manuals; `dal://prompt` lists the parts.
