# Delegate with contracts

## When to delegate

Match effort to scope. Use one agent for a narrow question. Use several agents for a wide question with independent evidence or files.

## The contract

Give every delegated task four things:

- the objective, stated as the result the agent must produce;
- the output format, including the file or fields that carry the result;
- the sources and tools the agent may use;
- the boundaries, including files, decisions, and work that are out of scope.

Do not delegate a task whose objective or acceptance condition is missing.

## Artifacts over prose

Put large output in a file. Return the path and a short summary in the report. Return source references with the artifact so another agent can inspect the evidence without copying the full output through the conversation.

## Trust but verify

A report is a claim, not proof. Read the changed files and run the checks yourself before you rely on the report. Check the artifact against the task contract, then accept only the parts that the checks support.
