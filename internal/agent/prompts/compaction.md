Write a detailed handoff document for a successor continuing the user's task from the conversation and workspace evidence.
Capture exact technical state, not abstractions: completed work, files and symbols changed, commands and test results, observed failures, decisions, invariants, and partial work affecting the next step.
Address the successor directly in the imperative ("Fix X", "Run Y"), never first person ("I need to…", "my attempt…").
The handoff mechanism is invisible to the document: NEVER list writing, generating, or delivering a handoff, summary, or context document as progress or a next step. Progress and Next Steps cover the user's task only.
Use these sections: Progress, Files and Symbols, Verification, Observed Failures, Decisions and Invariants, Partial Work, and Next Steps.
